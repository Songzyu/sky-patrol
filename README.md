# Sky Patrol

Godot 4로 만든 2D 비행기 슈팅 게임입니다. 적기를 격추하며 점수를 쌓고, 갈수록 어려워지는 웨이브를 버티세요. 세 번 피격되면 게임이 끝나며 최고 점수는 기기에 저장됩니다.

## Windows에서 실행

[최신 릴리스](https://github.com/Songzyu/sky-patrol/releases/latest)에서 `SkyPatrol-Windows-x64.zip`을 내려받아 압축을 풀고 `SkyPatrol.exe`를 실행하세요. Godot 설치는 필요 없습니다.

| 조작 | 키 |
| --- | --- |
| 시작, 이어하기, 재도전 | Enter |
| 이동 | 방향키 또는 WASD |
| 연속 발사 | Space 길게 누르기 |
| 일시정지 | P 또는 Esc |

## Godot에서 열기

Godot 4.7.2에서 `project.godot`을 가져온 뒤 F5를 누르면 실행됩니다. 같은 버전의 내보내기 템플릿을 설치하면 `Windows Desktop` 프리셋으로 Windows x64 실행 파일을 만들 수 있습니다.

[Godot 엔진 라이선스](https://godotengine.org/license/)와 타사 라이선스 고지는 Windows 배포 파일에 포함되어 있습니다.
